# CoCoCheck documentation

- [Usage](usage.md): The command-line options, selecting the commits to check, the output, the JSON

- [Using CoCoCheck in CI](ci.md): Checking pull requests and pushes with the GitHub Action, in a

- [Configuration](configuration.md): The configuration file, ignored and forbidden commits, and the

- [Rules](rules.md): All rules, their settings, and how to change their severity.
